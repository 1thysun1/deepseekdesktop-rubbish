# DeepSeek Windows Design

## External grounding

DeepSeek's API is OpenAI-compatible and supports a `base_url` of `https://api.deepseek.com`; as of 2026-05-29 the official quick-start still shows `deepseek-chat` and `deepseek-reasoner`, but also says those names are scheduled for deprecation on 2026-07-24. This design keeps model IDs configurable so the installed product can switch to new DeepSeek model IDs without changing higher-level agent logic.

Reference programs checked:

- `openai/codex`: CLI-first coding agent shape; local shim delegates to a Node/native implementation.
- `chatboxai/chatbox`: Electron desktop AI client with provider abstraction.
- `open-webui/open-webui` and `open-webui/desktop`: OpenAI-compatible provider support and desktop packaging direction.
- OpenAI Codex safety docs: sandbox + approval split as a reusable product model.

Login/account flow is split:

1. API mode: user stores `DEEPSEEK_API_KEY` locally.
2. Web account mode: desktop opens `https://chat.deepseek.com/` for browser login. The app does not scrape browser cookies by default; it treats web login as a user-facing account management path.

## Codex-like runtime shape used as a rough reference

Reference notes were kept generic for publication:

- CLI shim delegates to Node and a packaged agent implementation.
- CLI package: `@openai/codex` with platform-specific optional native packages.
- Desktop: Windows packaged Electron/MSIX app under `C:\Program Files\WindowsApps\OpenAI.Codex_...\app\Codex.exe`.
- Runtime memory: multiple Electron/agent processes with working sets roughly from tens of MB to ~236 MB per large process during this session.
- Installer reference is a Microsoft Store Installer style executable, signed by Microsoft, not a generic NSIS-style app installer.

## Product goals

- Same command vocabulary across CLI and desktop.
- OpenAI-compatible DeepSeek client with explicit model routing:
  - `deepseek-chat`: default fast coding/chat path.
  - `deepseek-reasoner`: explicit reasoning path for planning/debugging.
- Codex-like guardrails:
  - workspace-scoped file operations by default.
  - command execution disabled unless explicitly enabled.
  - destructive command denylist.
  - API key stored outside project files.
  - no implicit browser-cookie harvesting.
- Desktop memory target similar to Codex desktop:
  - Electron main + renderer + CLI worker.
  - idle target: 150-350 MB aggregate working set.
  - active target: 300-700 MB depending on terminal, diff view, and context size.

## CLI command design

```text
deepseek ask <prompt> [--model deepseek-chat|deepseek-reasoner]
deepseek chat [--workspace <path>]
deepseek config set-key <key>
deepseek config show
deepseek login
deepseek doctor
deepseek run <command> --allow-commands
```

## Desktop design

Desktop is a thin Electron shell:

- main process owns windows, protocol handlers, and OS integration.
- renderer provides chat, settings, workspace picker, and terminal pane.
- preload exposes a narrow IPC API.
- model calls reuse the same config path as CLI.

Config paths:

- `%APPDATA%\DeepSeekWindows\config.json`
- `%APPDATA%\DeepSeekWindows\sessions\`
- `%LOCALAPPDATA%\DeepSeekWindows\logs\`

## Safety policy

Default policy:

- network allowed only to DeepSeek API and account web URL unless user changes settings.
- shell execution off by default.
- file writes confined to selected workspace.
- secrets redacted in logs.
- destructive commands blocked:
  - `Remove-Item -Recurse`
  - `del /s`
  - `rd /s`
  - `git reset --hard`
  - `format`
  - `cipher /w`

Command execution policy:

1. parse command.
2. reject denylisted patterns.
3. require `--allow-commands`.
4. run with selected workspace as CWD.
5. stream output to UI/CLI.
6. include command, cwd, exit code in session log.

## Installer design

The installer is intentionally simple and reviewable:

- generated by Windows IExpress as `DeepSeek Installer.exe`.
- runs `install.ps1`.
- installs files to `%LOCALAPPDATA%\Programs\DeepSeekWindows`.
- creates `deepseek.cmd` and `deepseek.ps1` launchers.
- appends install directory to user PATH.
- creates desktop shortcut for `DeepSeek Desktop`.
- runs `npm install --omit=dev` if Node/npm is available.

For production, replace IExpress with MSIX or electron-builder NSIS once code signing material is available.
